## 🧮 Mathematical Concept

The heart shape is generated using mathematical parametric equations involving sine and cosine functions.

### X-coordinate

```python
x = 15 * sin(t) ** 3
```

### Y-coordinate

```python
y = 12*cos(t) - 5*cos(2*t) - 2*cos(3*t) - cos(4*t)
```

These equations generate the coordinates of a heart-shaped curve.

The coordinates are then scaled and plotted to create the final heart animation.

## ⚙️ How the Project Works

### 1. Python Version

The original Python implementation uses:

- `math` module for mathematical calculations.
- `turtle` module for graphics.
- Loops to generate and draw heart coordinates.
- Red color on a black background.

### 2. Web Version

The browser-based implementation uses:

- HTML to create the page structure.
- CSS to style the background and glowing text.
- JavaScript to calculate mathematical coordinates.
- HTML Canvas API to draw the heart.
- `requestAnimationFrame()` to render the animation.

## 🚀 Getting Started

### Option 1: Run the Web Version

No installation or additional dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/Sehgal1001/python-heart-animation.git
```

2. Open the project folder:

```bash
cd python-heart-animation
```

3. Open `index.html` in your browser.

That's it! Enjoy the heart animation.

### Option 2: Run the Python Version

Make sure Python 3 is installed.

1. Clone the repository:

```bash
git clone https://github.com/Sehgal1001/python-heart-animation.git
```

2. Navigate to the folder:

```bash
cd python-heart-animation
```

3. Run the Python file:

```bash
python redheart.py
```

The Turtle Graphics window will display the mathematical heart animation.
